🛒 Blinkit Sales Analysis Dashboard

📌 Project Overview
The Blinkit Sales Analysis Dashboard is a data visualization project that provides meaningful insights into sales performance, customer behavior, and outlet distribution of Blinkit (India’s last-minute delivery app).
The dashboard helps in analyzing key business metrics and supports better decision-making through interactive and visually appealing reports.

🎯 Objective

The main objective of this project is to:

Analyze sales performance across different outlets
Identify top-performing product categories
Understand customer preferences based on ratings
Compare outlet types, sizes, and locations
Provide data-driven insights for business growth
📊 Key Features
📈 Total Sales Analysis – Displays overall revenue performance
💰 Average Sales – Shows average transaction value
📦 Number of Items – Total items sold across outlets
⭐ Customer Ratings – Average rating insights
🏪 Outlet Analysis – Comparison by size, type, and location
🥗 Product Category Insights – Performance of item types
🧈 Fat Content Analysis – Sales split by low fat & regular
📅 Trend Analysis – Outlet establishment growth over years
🎛️ Interactive Filters – Dynamic filtering for better insights
🛠️ Tools & Technologies Used
Power BI (for dashboard creation)
Microsoft Excel / CSV (data source)
Data Cleaning & Transformation
Data Visualization Techniques
